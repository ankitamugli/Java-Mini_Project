# 🧑‍💻 Java Mini Project - Employee Management System

## 📌 Project Overview
This is a simple **Java-based Employee Management System** developed in Eclipse IDE.  
It helps manage employee data such as adding, viewing, updating, and deleting employee records using a console-based application.

---

## 🚀 Features
- Add new employee details
- View all employee records
- Search employee by ID
- Update employee information
- Delete employee record
- Simple console-based interface

---

## 🛠️ Technologies Used
- Java (Core Java)
- Eclipse IDE
- Git & GitHub
